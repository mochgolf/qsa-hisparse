# W7 launch, scope and regression

1. `src/sglang_qsa_hisparse/scope.py`: implement the fixed contract in the
   module docstring (read the served model's architectures the way SGLang's
   `ModelConfig` does from the published model configuration, including
   override arguments; cache per process; raise `ScopeUndecidable`). Tests
   with temporary model directories.
2. `src/sglang_qsa_hisparse/launch.py` (`python -m sglang_qsa_hisparse.launch
   -- <sglang launch_server args>`): create a private directory with this
   package's dist-info (entry point `qsa_hisparse`), put it on `PYTHONPATH`
   for the server and every spawned process, refuse to start if
   `SGLANG_PLUGINS` excludes `qsa_hisparse` or the entry point is not
   discoverable in a child interpreter, set `SGLANG_QSA_ACTIVATION_DIR`, start
   the server, and report readiness only after activation records exist for
   every scheduler/TP rank (tp size from the arguments) with the requested
   features; otherwise stop the server it started and exit non-zero. Never
   stop processes it did not start. CPU tests with a fake server process.
3. Port the fork's `scripts/qsa_service.py` and
   `test/qsa_hisparse/test_service_control.py` to use the launcher
   (`tools/qsa_service.py`, `tests/service/`). Deselect
   `ServiceLifecycleTests` in automated runs (rule 8); keep them runnable on
   request.
4. `tests/regression/`: plugin installed but off ⇒ `HookRegistry` empty and
   the pinned upstream subset from `docs/baseline.md` passes in-process with
   the plugin loaded; compat on with a non-target architecture ⇒ scoped hooks
   delegate to the originals (use the hooks merged from other workstreams;
   write the test against the `scope` contract now and mark it
   `integration`); inventory completeness: parse Appendix A and the fork diff
   and fail on any unmapped hunk.

Owned paths: `scope.py`, `launch.py`, `tools/qsa_service.py`,
`tests/{scope,launch,service,regression}/`.
