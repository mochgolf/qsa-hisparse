# W8 evidence tooling

Inputs: `docs/baseline.md` (gaps 5–7, the G2 job list), fork
`test/manual/qsa_hisparse_prefix_*.py`.

1. Neutral checkpoint-byte observer `tools/evidence/observer.py`: enabled by
   an environment variable, it records SHA-256 of restored and captured raw
   K/V bytes, compressed index, pending C4 ring and rope positions, and every
   Mamba/PLE state tensor, per request, layer group and TP rank, to JSONL. It
   must produce identical records for the fork and the plugin, so it attaches
   to definitions that exist in both (e.g. via a `sitecustomize`-loaded wrapper
   around the runtime's `capture_prefix`/`restore_prefix` found by import
   path in either tree) and must not change computation or synchronization
   beyond what hashing requires (document the extra syncs).
2. Offline comparator `tools/evidence/compare.py`: F vs P for token IDs,
   `cached_tokens`, normalized ledgers (strip time-based rids/salts), observer
   hashes, and memory figures; exits non-zero on any difference and prints
   the first divergence.
3. Reduced deterministic compat-only profile (`tools/evidence/compat_profile.json`
   and a run script): TP2, deterministic inference, a context and
   `--max-total-tokens` that fit raw KV without offload on 2x48 GB, fixtures
   derived from the frozen fixture file by truncation rule fixed in advance
   (no selection by results). Fork arm: V3 unset; plugin arm:
   `SGLANG_QSA_MODEL_COMPAT=1`.
4. CPU tests for all three with synthetic inputs, including a comparator
   test that detects a single flipped byte and a reordered ledger.

Owned paths: `tools/evidence/`, `tests/evidence/`.
