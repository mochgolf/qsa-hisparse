The fork runtime package is already in `src/sglang_qsa_hisparse/hisparse/`
(verbatim, imports rewritten). Your job is to prove it.

1. Port the fork tests `test/qsa_hisparse/test_runtime.py`, `test_slots.py`,
   `test_single_request.py`, `test_gather.py` into `tests/runtime/` with only
   import-path changes (mapping in PLAN.md). Keep every assertion.
2. Where a test reaches SGLang behavior that the fork changed (e.g. FP8

   do not reimplement it: mark the test `integration` and name the inventory
   rows it needs.
3. Add `tests/runtime/test_moved_sources.py`: for every moved module, assert
   that its text equals the fork file at `ee8fe158d6` after applying exactly
   the documented import rewrites (read the fork with `git show`).
4. Document in `docs/runtime.md` every private SGLang definition the runtime
   relies on (e.g. `mamba_pool._slot_siblings`, `qsa_rope_position_buffer`,
   `ReqToTokenPool.req_generation`) with the pinned definition providing it.
   Put their dotted names in `RUNTIME_DEPENDS` in a new module
   `src/sglang_qsa_hisparse/hisparse/depends.py` (moved modules stay
   verbatim) and pin them with `tools/fingerprint.py write runtime ...`.
   W4's runtime-construction hook (row Q03) passes `depends=RUNTIME_DEPENDS`,
   so drift in any of them fails activation. Entries must be functions or
   classes; for an instance attribute, name the method that creates it.

`tests/runtime/`, `docs/runtime.md`, `src/sglang_qsa_hisparse/fingerprints/runtime.json`
(`hisparse/depends.py` included).
