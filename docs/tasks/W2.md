# W2 scheduler and lifecycle

Rows: S01–S09, B01–B06, P01, P02, M01–M04 (S01, B06, P01, P02, M01, M03 are
the host-prefix call sites W6 verifies; you implement them).

Fork files: `managers/scheduler.py`, `managers/schedule_policy.py`,
`managers/scheduler_components/{batch_result_processor,weight_updater}.py`,
`mem_cache/{allocation,common,memory_pool}.py`, `mem_cache/allocator/paged.py`.

1. Implement each row in `src/sglang_qsa_hisparse/patches/hisparse/scheduler.py`,
   `patches/hisparse/lifecycle.py`, and (for model_compat rows such as M04)
   `patches/model_compat/lifecycle.py`, with fingerprints in matching
   `fingerprints/<module>.json`. Generic model_compat rows obey the
   target-model scope (PLAN.md rule 9; call
   `sglang_qsa_hisparse.scope.target_model_active()`, monkeypatched in tests).
2. Preserve the release order exactly: prefix capture/`before_release` →
   runtime release (drain GPU and copy events) → `cache_finished_req`
   (logical free inside the free group) → `req_to_token_pool.free` →
   `mark_kv_released` → `after_release(lease)` → allocator free-group end →
   `after_logical_flush` (physical slot reuse). Add
   `tests/lifecycle/test_release_order.py` that records the call order with
   independent fakes for each path (finish, abort, rollback of a failed
   restore, flush) and asserts it, plus a negative test that a physical slot
   is never reusable before the logical flush.
3. Port the fork's edits to the pinned upstream tests it touched
   (`test_batch_result_processor_hidden_states.py`,
   `test_scheduler_chunked_req_gate.py`) as plugin tests run with the hisparse
   patches active; the pinned originals must still pass with the plugin off.
4. With the plugin off, every hooked function must be the pinned original
   (test via `inspect.unwrap` identity after a no-switch `plugin.load()`).

Owned paths: `patches/*/scheduler.py`, `patches/*/lifecycle.py`, their
fingerprint files, `tests/lifecycle/`.
