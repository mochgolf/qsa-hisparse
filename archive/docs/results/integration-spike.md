## V1

Both ranks resolved the real `QwenSparseAttnBackend._forward_paged_attention` FA2 implementation from `sglang.kernels.ops.attention.flash_attention` with one row, 12 Q heads, one KV head, head dimension 256 and expanded width 2051. Each layer had its own captured call and a pool that rejects the wrong layer ID.

Each rank saved 96 case records: A/B × four real positions × 12 layers. The positions cover raw-tail remainders 0, 1, 2 and 3. Case metadata records the actual layer/pool layer, expanded valid count and pending tail IDs. Immutable packed bytes separately populated the resident pool and graph staging. Actual K and V bytes, including pending tail members, matched the immutable source. The same graph replayed two distinct payloads per case; each output was bitwise equal to the independently populated resident call and changed across payloads.

The actual acceptance checker rejected mutations of physical mapping, K bytes, V bytes, K scale and V scale. Rank graph P95s were 0.305152 and 0.312320 ms over 192 replays each. FP64 diagnostics remain `INDEPENDENT_KERNEL_ACCURACY_NOT_QUALIFIED`: maximum absolute error 0.001224853, maximum true relative error 0.004568290 and no zero-reference entries. No mathematical tolerance was introduced.

## V2

For every layer and rank, `close(..., producer_event=None)` rejected before changes to expected bytes, pending events, completion events or host sentinel. The API no longer has a dependency boolean. Incomplete close calls at tail lengths 0/1/2/3 all rejected; a successful close cleared the tail; the same request then appended and closed a second C4.

The two-slot allocator rejected a third admission. Pending evict and release calls rejected until explicit completion acknowledgement. Old leases rejected after generation reuse. Two requests used request-owned host rows for distinct bytes at the same logical block. Each legal close executed a producer-event wait.

Refetch returns a real H2D completion event. The consumer stream waits on that event before unpack and the production paged-decode call. Its output was bitwise equal to the same kernel invoked on an independently populated resident pool for all 12 layers and both ranks. Mapping uniqueness, selected-set completeness and scale state were checked.

Per rank the 12 layers transferred 73,728 D2H bytes and 49,152 H2D bytes. Aggregate CUDA-event time was 0.648064/0.638432 ms D2H and 0.294656/0.296512 ms H2D on rank 0/1; aggregate layer wall time was 1348.84/1360.39 ms. These timings include the controlled producer delay and lifecycle checks and are diagnostic.

## V4 correctness and complete timing scope

The forced segment now uses logical block 65534 while sequence length is 65536, so it cannot take the newest-slot shortcut. It closes a variant-1 generated record onto a variant-0 host row, completes producer-gated D2H, advances the lifecycle, poisons the old GPU tail, and asks the real GPU resolver to fetch the non-newest block. Every request/layer/replay asserted a positive miss count, the exact host source, a normal hot destination, and append-derived variant-1 bytes. Poisoning the destination made the same checker reject the missing-copy counterexample. The segment then fully reset host, buffers, mappings, LRU and generated state.

Timed generated records use variant 1 while pre-window completed host records use variant 0. The independent version map follows every close and validates naturally refetched generated bytes. Trace lookup, tensor construction and CPU payload synthesis are precomputed outside the CUDA events. The measured interval contains GPU metadata copies, tail production, producer-gated D2H, dependency waits, the real GPU resolver and H2D, selected-record gather, and packed K/V unpack. The gather output is checked against both physical buffer locations and the independent versioned oracle.

All B=1/4/8 arms retained separate 1.5/6/12 GiB pinned host storage per rank, correct NUMA placement, three resets and 128 monotonic steps. The raw files contain 2,304 unique rank samples and 1,152 step-paired maxima.
